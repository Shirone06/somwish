# 🎂 ระบบอวยพรวันเกิด คุณส้ม — C.C. Content

เว็บให้พนักงานกรอกคำอวยพร + รูปตัวเองแบบออนไลน์ แล้วนำมาฉายเป็นสไลด์โชว์ในงาน
เก็บข้อมูลบน **Firebase Firestore** (แพลนฟรี Spark) — รูปย่ออัตโนมัติแล้วเก็บในฐานข้อมูลเลย จึง **ไม่ต้องผูกบัตร**

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก มีปุ่มไปหน้าฟอร์ม / หน้าสไลด์ |
| `form.html` | หน้าพนักงานกรอก (ชื่อ + คำอวยพร + รูป) |
| `slideshow.html` | หน้าฉายสไลด์ (สำหรับผู้จัด) |
| `firebase-config.js` | **ไฟล์เดียวที่ต้องแก้** — ใส่ค่า Firebase + ชื่อคุณส้ม |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล |
| `firebase.json` | ตั้งค่าสำหรับ Firebase Hosting |

## ขั้นตอนติดตั้ง (ครั้งเดียว ~10 นาที)

### 1) สร้างโปรเจกต์ + เปิด Firestore
1. เข้า https://console.firebase.google.com → **Add project** (หรือใช้โปรเจกต์เดิมก็ได้)
2. เมนูซ้าย **Build → Firestore Database → Create database**
3. เลือก **Start in production mode** → เลือก location `asia-southeast1` (สิงคโปร์ ใกล้ไทยสุด) → Enable

### 2) เอาค่า config มาใส่
1. กดเฟือง ⚙ → **Project settings** → เลื่อนไปหัวข้อ **Your apps**
2. กดไอคอน **`</>` (Web)** → ตั้งชื่อแอปเช่น `somwish` → **Register app**
3. ก๊อปบล็อก `firebaseConfig = { ... }` มาวางแทนใน **`firebase-config.js`**
   (แก้ชื่อ `HONOREE_NAME` / `COMPANY_NAME` ได้ตามต้องการ)

### 3) วางกฎความปลอดภัย
1. **Firestore Database → แท็บ Rules**
2. ลบของเดิม แล้วก๊อปเนื้อหาจากไฟล์ **`firestore.rules`** มาวาง → **Publish**

> กฎนี้ให้ทุกคน "ส่ง" และ "อ่าน" คำอวยพรได้ แต่ห้ามแก้/ลบ และจำกัดขนาดข้อมูลกันสแปม

### 4) เอาขึ้นออนไลน์ (เลือกทางใดทางหนึ่ง)

**ทาง A — Firebase Hosting** (แนะนำ อยู่ค่ายเดียวกัน)
```bash
npm install -g firebase-tools
firebase login
cd somwish
firebase use --add        # เลือกโปรเจกต์ที่สร้างไว้
firebase deploy --only hosting
```
เสร็จแล้วจะได้ลิงก์ เช่น `https://ชื่อโปรเจกต์.web.app`

**ทาง B — GitHub Pages** (ถ้าถนัด GitHub อยู่แล้ว)
- push ทุกไฟล์ขึ้น repo → Settings → Pages → เลือก branch `main` / root → Save
- จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## วิธีใช้งานจริง

**ส่งให้พนักงาน:** แชร์ลิงก์ `.../form.html` ทาง LINE
พนักงานเปิด → พิมพ์ชื่อ + คำอวยพร → เลือก/ถ่ายรูป → กดส่ง (ทำบนมือถือได้เลย)

**วันงาน (ผู้จัด):** เปิดลิงก์ `.../slideshow.html`
1. ดูว่ามีคำอวยพรกี่คน (กด **รีเฟรช** ถ้ามีคนส่งเพิ่ม)
2. เพิ่ม **รูปคุณส้ม** สำหรับช่วงเปิด
3. เลือกเพลง / ตั้งเวลา → กด **เริ่มโชว์** → กด **F** เต็มจอ

### ลำดับการเล่น
1. **หน้าเปิด** — โลโก้ + "สุขสันต์วันเกิด คุณส้ม"
2. **ช่วงที่ 1** — รูปคุณส้ม ซูมนุ่มๆ พร้อมคำอวยพรของทุกคนคลอด้านล่าง
3. **หน้าคั่น** — "คำอวยพรจากพวกเราทุกคน"
4. **ช่วงที่ 2** — ไล่ทีละคน: รูป + ชื่อ + คำอวยพรของคนนั้น
5. **หน้าปิด** — จากทีมงาน C.C. Content (เล่นวนซ้ำได้)

## จัดการ / แก้ปัญหา
- **ลบคำอวยพรไม่เหมาะสม:** Firebase Console → Firestore → คอลเลกชัน `wishes` → เปิดเอกสาร → ลบ
- **ค่า config เผยแพร่ในหน้าเว็บ ปลอดภัยไหม?** ปลอดภัยตามการออกแบบของ Firebase — ความปลอดภัยจริงอยู่ที่ **Rules** ที่วางไว้แล้ว
- **เก็บได้กี่คน?** รูปย่อ ~150–200KB/คน บนโควตาฟรี 1 GiB = หลายพันคน เหลือเฟือ
- **หน้าสไลด์ขึ้นว่าโหลดไม่สำเร็จ:** ตรวจว่า Publish `firestore.rules` แล้ว และค่าใน `firebase-config.js` ถูกต้อง
